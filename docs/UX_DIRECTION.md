# UX Direction

The current interface is functional, but it still reads a little too much like a generic SaaS/admin dashboard.

Target direction:

- Compact, immersive management-game console inspired by Upload Labs.
- Always-visible operational status: cash, reputation, queue pressure, inventory, staff, and after-sales risk.
- Game verbs instead of admin verbs: Customer Desk, Build Bay, Warehouse, Supplier Desk, Market Terminal, Warranty Desk, Upgrade Board.
- Dense but readable panels, with clear action loops and strong state feedback.
- Avoid broad redesigns for now; make incremental changes that preserve the current gameplay systems.

Suggested future redesign phases:

1. App shell and station navigation.
2. Dashboard command center.
3. Customer and quote workflow.
4. Inventory, test bench, and refurbish workflow.
5. Market, supplier, resale, and warranty workflow.
6. Microinteractions and polish pass.
